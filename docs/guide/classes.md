# Classes

Open **Classes** in the menu.

- **Scholars** see the classes they're in.
- **Mentors** see the classes they mentor first, then every class at the school.
- **Admins** see every class and can create, archive and delete them.

## A class's page

Each class has its name, term and meeting time, a description, what's coming
up on its calendar (events and due dates), its assignments, and its mentors and
scholars, and a link to the class chat. See [Assignments](assignments.md),
[Calendars](calendar.md) and [Chat](chat.md).

Mentors and admins see usernames. Scholars see their classmates' names only.

## Creating a class (admins)

1. Select **New class**.
2. Enter the **name**. Optionally add the **term** ("2026–27", "Fall 2026" — use
   the same words for every class in a term, so you can filter by it), **when it
   meets**, a **color**, and a **description**.
3. Select **Create class**. You're taken to the class's **Members** page.

The description can have simple formatting: `**bold**`, `*italic*`, lists with
`- `, links with `[text](https://…)`, and a blank line between paragraphs.

## Members

On the class page, select **Members**.

- **Add scholars:** tick the scholars to add (type in the box to find them
  quickly), then select **Add selected scholars**.
- **Add mentors** (admins only): the same, choosing from mentors and admins. A
  class can have several mentors.
- **Remove** takes someone out of the class. Nothing they did in the class is
  deleted.

A class's mentors can edit its details and add or remove its scholars. Only
admins choose mentors.

To add many scholars to classes at once, include a **Classes** column when you
[import people from a spreadsheet](people.md#importing-from-a-spreadsheet).

## At the end of a term (admins)

**Archive** a class when it's over. It's kept, read-only, with its members, but
no longer shows up for scholars or in the current classes. Find it again under
**Classes → Archived classes**, and bring it back if needed.

An archived class can be deleted for good: type its name to confirm. That can't
be undone.
